Task:
For each pathway listed below, generate a table with the following columns:
Pathway | Administration | Regulation | Effect | Rationale | Ref(s)

Rules:
Only focus on breast cancer 

For each pathway, produce 8 rows:

Before administration (baseline breast cancer state)

After administration (drug-induced state)

For Before, determine whether baseline up/down regulation predicts sensitivity or resistance to <DRUG_NAME>.

For After, describe how <DRUG_NAME> mechanistically regulates that pathway (up/down) and what effect that causes (sensitive/resistant).

Provide a clear mechanistic rationale for each regulation/effect pair.

Add citation(s): Citations (mandatory for all key claims)
•	Use:
o	PMID
o	NCT IDs
o	FDA/EMA label IDs
o	ChEMBL IDs
o	DrugBank IDs
o	MSigDB / Reactome / KEGG / GO / ImmuneDB / ImmunoSigDB identifiers
•	Every claim about:
o	Mechanism of action (MOA)
o	Predictive/prognostic biomarkers
o	Sensitivity mechanisms
o	Resistance mechanisms
o	Subtype-specific behavior
o	Pathway associations
o	Synonyms / identifiers (ChEMBL / DrugBank)
o	Contraindications / safety
→ must have at least one citation.
Breast cancer subtype awareness
When possible, explicitly stratify findings by subtype:
•	HR+/HER2– (Luminal A/B)
•	HER2+
•	Triple-negative breast cancer (TNBC)
•	gBRCA1/2-mutated / HRD+
•	Basal-like / HER2-enriched / Luminal A / Luminal B

Keep rationales 1–2 sentences, mechanistic, and specific. If breast-only evidence is required, add a short tag in Rationale when using cross-cancer data (e.g., “Mechanism shown in ovarian cancer but relevant to taxane resistance”).
